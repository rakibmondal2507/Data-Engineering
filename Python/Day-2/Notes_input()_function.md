## Input and Variables
+ Using input() alone reads the user's response but immediately discards it.
  To keep the value, assign it to a variable.

## **Hard coded (static) value**
fixed piece of data written directly into your code that never change at runtime.

## **Input() makes your program interactive**
Input lets your program ask questions and react to what the user types, making it feel alive.
