- Python automatically detect Data Types.
- **Dynamic** : Data Types can change any time
  
```python
a = 10
```
**int** - integer : whole numbers without decimal

```python
b = 3.15
```
**float** - Numbers with decimal points.

```python
c = "Hello"
d = 'Hi'
e = "1234" #This is still as a considered as String .
```
**str**
 - string: represent text or sequence of characters.
 - written inside single or double quotes.

```python
f = True
g = False
```
**bool**
- Boolean : can be either True or False.
- used to handle logic and decision making.
- True and False are case-sensitive; they must start with a capital latter.




  ```python
  h = None
  ```
  **None**
  - means "no value", "nothing" or "unknown"
  - it's used to show absence of any data.
 

## Data Types summary
- **Each value have a data type**
  This helps python decide how to handle value
- **It automatically detects data types.**
- **Dynamic : Data types can change anytime.**
- **3 Categories**
    - **No Value:** NoneType
    - **Single value:** int, str, bool, float, complex
    - **Multiple values:** set, tuple, dict, list
- Values are objects of a data type class
